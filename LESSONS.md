# Lessons for KOML

Synthetic test evidence validates the assumption that explicit status, blocking flags and reference dates suffice for deterministic classification. It does not validate whether operators will enter all important unknowns or keep answers current.

The domain requires distinguishing unanswered from open: deferred questions still affect decisions. A future deadline is legitimate, while future creation relative to the reporting date is a schema error. Provenance must remain visible even for filtered question lists.

Operating rule: keep a fixed reference date, independent expected ID sets, and a mutation test for every classification tool. Never turn synthetic accuracy into a claim of real-world usefulness.
